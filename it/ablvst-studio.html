AblVST Studio

UN PROGETTO ORDINATO È IL PUNTO DI PARTENZA

E’ importante avere una struttura ordinata dei propri progetti

Prima: una struttura fatta bene

Tieni una cartella generale, per esempio Progetti di Ableton, con una sottocartella per ogni progetto. Dentro conserva i file .als insieme a Samples, Backup e agli altri file collegati. Se i percorsi sono sparsi o l'archivio è incompleto, nessun lettore — nemmeno questo — può darti una lettura davvero fedele.

Libreria di Set

Scansiona la cartella generale e AblVST Studio troverà i Set, mostrando solo la versione più recente o, a scelta, tutte quelle presenti. Ricorda l'ultima cartella e l'ultimo Set che hai analizzato, così riprendi da dove avevi lasciato.

Panoramica tecnica del Set

Trovi subito versione di Ableton Live, BPM, indicazione di tempo e dimensione del file. Sotto, l'inventario completo del progetto: tracce audio e MIDI, gruppi, Return, Master, clip e dispositivi.

Plugin map

Ogni plugin di terze parti viene elencato con nome, produttore, formato, tipo, identificatore, numero di istanze, tracce, Rack e posizione. Puoi filtrare per plugin mancanti o disponibili e saltare direttamente dalla mappa alla traccia che lo usa.

Database locale dei plugin

Scansiona i plugin installati sul computer e costruisce un inventario ricercabile, raggruppabile per nome, produttore, formato, tipo, versione, architettura o percorso.

Media Health

Controlla i riferimenti audio di clip, Simpler e Sampler/MultiSampler sui percorsi salvati, e ti dice cosa è stato trovato, cosa manca, da dove arriva il percorso e quali tracce o dispositivi lo usano. I file supportati si riproducono al volo con un semplice clic sul nome del media, la loro posizione si apre con un clic, e la lista dei mancanti si copia o si esporta.

Session map e Rack annidati

Mostra la gerarchia delle tracce, le device-chain, i Rack annidati e i dispositivi interni. I plugin mancanti vengono segnalati direttamente nella catena della traccia, con un collegamento diretto alla Plugin map.

Routing e flusso del segnale

Analizza mandate, Return, catene effetti e le tracce che alimentano ogni Return, rendendo leggibile il flusso del segnale senza dover aprire Ableton Live.

Export professionale del Set

Esporta la lista dei plugin richiesti in CSV o PDF: modalità Summary, una riga per plugin, oppure Detailed, con una riga per ogni istanza, traccia, gruppo, Rack e posizione.

I report indicano nome del Set, versione di Live, utilizzo e disponibilità locale, e vengono generati offline senza scrivere nulla accanto al file .als.

Preferenze e diagnostica

Da qui gestisci le versioni di Ableton Live installate, le cartelle plugin standard e personalizzate, la visibilità delle versioni dei Set, la lingua, la cache e il log dell'applicazione.

Apri con la versione giusta di Live

Se sul computer ci sono più versioni di Ableton Live installate, AblVST Studio ti mostra quelle compatibili con il Set e puoi decidere con quale versione di Ableton Live aprire il progetto.

Windows e macOS

Su Windows vengono rilevati i plugin VST2 e VST3, inclusi i VST3 in formato file e bundle. Su macOS sono supportati anche gli Audio Units, oltre a VST2 e VST3. L'app macOS gira in una finestra nativa Cocoa/WebKit e non dipende da Chrome.

Offline e privato

L'analisi dei Set avviene interamente sul tuo computer. I file originali non vengono toccati, i dati derivati restano nella cache locale e nessun progetto o metadato viene mai caricato online.
