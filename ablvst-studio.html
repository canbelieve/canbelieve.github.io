Prima: una struttura fatta bene

First: build a proper archive

Usa una cartella generale, per esempio Progetti di Ableton, con una cartella per ogni progetto. Dentro ogni progetto conserva il file .als, le versioni, Samples, Backup e gli altri file relativi. Con percorsi sparsi o archivi incompleti, nessun lettore può promettere una rappresentazione fedele.

Use one general folder, such as Ableton Projects, with one folder per project. Keep the .als file, versions, Samples, Backup and related files inside each project folder. With scattered paths or incomplete archives, no reader can promise a faithful representation.

Libreria di Set

Set library

Scansiona una cartella generale, trova i Set anche nelle sottocartelle e scegli se mostrare solo la versione più recente o tutte le versioni. La libreria ricorda l'ultima cartella e l'ultimo Set analizzato.

Scan one project root, find Sets in subfolders and choose whether to show only the newest version or every version. The library remembers the last folder and last inspected Set.

Panoramica tecnica del Set

Technical Set overview

Vedi versione di Ableton Live, BPM, indicazione di tempo, dimensione del file, locator, tracce audio e MIDI, gruppi, Return, Master, clip, automazioni e dispositivi.

See the Ableton Live version, BPM, time signature, file size, locators, audio and MIDI tracks, groups, Returns, Master, clips, automation and devices.

Plugin map

Plugin map

Elenca ogni plugin di terze parti con nome, produttore, formato, tipo, identificatore, numero di istanze, tracce, Rack e posizione del device. Filtra per tutti, mancanti o disponibili e passa dalla mappa plugin alla traccia utilizzatrice.

List every third-party plug-in with name, vendor, format, type, identifier, instance count, tracks, Rack and device position. Filter all, missing or available items and jump between a plug-in and its track.

Database locale dei plugin

Local plug-in database

Scansiona i plugin installati sul computer e crea un inventario ricercabile e raggruppabile per nome, produttore, formato, tipo, versione, architettura o percorso. Le versioni installate sono metadati locali informativi, non vengono confrontate con il Set e il database resta in sola lettura nella cache dell'app.

Scan installed plug-ins and create a searchable inventory grouped by name, vendor, format, type, version, architecture or path. Installed versions are local informational metadata, never compared with the Set, and the read-only database stays in the app cache.

Media Health

Media Health

Controlla i riferimenti audio di clip, Simpler e Sampler/MultiSampler sui percorsi salvati. Mostra file trovati, mancanti, origine del percorso, tracce e dispositivi utilizzatori; permette di riprodurre i file supportati, aprire la posizione e copiare o esportare la lista dei mancanti.

Check audio references from clips, Simpler and Sampler/MultiSampler against their saved paths. See found files, missing files, path origin, tracks and devices; play supported files, reveal their location and copy or export the missing list.

Session map e Rack annidati

Session map and nested Racks

Leggi la gerarchia delle tracce, i device chain, i Rack annidati e i dispositivi interni. I plugin mancanti sono indicati anche nella catena della traccia e la navigazione resta collegata alla Plugin map.

Read track hierarchy, device chains, nested Racks and internal devices. Missing plug-ins are also marked in the track chain, with navigation linked back to the Plugin map.

Routing e flusso del segnale

Routing and signal flow

Analizza mandate, Return, catene effetti e tracce che alimentano ogni Return. La vista Routing rende leggibile il percorso del segnale senza aprire Ableton Live.

Inspect sends, Returns, effect chains and the tracks feeding each Return. The Routing view makes signal flow readable without opening Ableton Live.

Export professionale del Set

Professional Set export

Esporta la lista plugin necessaria in CSV o PDF, in modalità Summary con una riga per plugin unico oppure Detailed con una riga per ogni istanza, traccia, gruppo, Rack e posizione.

Export the plug-in requirements as CSV or PDF in Summary mode, one row per unique plug-in, or Detailed mode, one row per instance, track, group, Rack and position.

I report includono nome del Set, versione di Live, utilizzo e disponibilità locale; vengono creati offline senza scrivere accanto al file .als.

Reports include the Set name, Live version, usage and local availability; they are created offline without writing beside the .als file.

Preferenze e diagnostica

Preferences and troubleshooting

Gestisci versioni di Ableton Live, cartelle plugin standard e personalizzate, visibilità delle versioni dei Set, lingua, cache e log applicativo generico. Le cartelle aggiunte dall'utente sono additive e i percorsi standard restano visibili anche quando non esistono.

Manage Ableton Live versions, standard and custom plug-in folders, Set version visibility, language, cache and the generic application log. User-added folders are additive and standard paths remain visible even when unavailable.

Apri con la versione giusta di Live

Open with the right Live version

Quando sono presenti più installazioni locali di Ableton Live, AblVST Studio può mostrarti le versioni compatibili e aprire il Set con quella scelta.

When multiple local Ableton Live installations are available, AblVST Studio can show compatible versions and open the Set with the selected one.

Windows e macOS

Windows and macOS

Su Windows vengono rilevati VST2 e VST3, inclusi plugin VST3 in formato file e bundle. Su macOS sono supportati VST2, VST3 e Audio Units. L'app macOS usa una finestra nativa Cocoa/WebKit, senza dipendere da Chrome.

Windows detects VST2 and VST3, including file-form and bundle-form VST3 plug-ins. macOS supports VST2, VST3 and Audio Units. The macOS app uses a native Cocoa/WebKit window without relying on Chrome.

Cosa non promette

What it does not promise

La disponibilità è un controllo locale prudente per nome e formato, non una garanzia di licenza o compatibilità. La versione del plugin salvata nel progetto .als, il confronto tra versioni, il sample rate, la bit depth e l'export JSON sono volutamente esclusi.

Availability is a conservative local name-and-format check, not a license or compatibility guarantee. Plug-in versions saved in the .als, version comparison, sample rate, bit depth and JSON export are intentionally excluded.

Offline e privato

Offline and private

L'analisi dei Set avviene sul tuo computer. I file originali restano intatti, i dati derivati finiscono solo nella cache del sistema e nessun progetto o metadato viene caricato online.

Set analysis happens on your computer. Original files remain untouched, derived data stays only in the system cache, and no project or metadata is uploaded online.
