AblVST Studio

Scopri cosa contiene un Live Set prima di avviare Ableton Live. AblVST Studio legge i file .als localmente e mostra i plugin richiesti, senza caricare il progetto completo.

See what is inside a Live Set before launching Ableton Live. AblVST Studio reads .als files locally and shows the required plugins without loading the full project.

Ispeziona prima di aprire Live

Inspect before opening Live

Quando un progetto non si apre, richiede troppo tempo o risale a molti anni fa, puoi capire subito quali strumenti ed effetti servono per riprodurlo fedelmente.

When a project will not open, takes too long to load, or comes from years ago, you can immediately see which instruments and effects are needed to reproduce it faithfully.

Tutto ciò che serve per il troubleshooting

Everything needed for troubleshooting

  • versione di Ableton Live usata dal set;
  • tracce, gruppi e Return;
  • routing, sends e catene effetti;
  • VST2, VST3 e Audio Units richiesti;
  • confronto con i plugin installati sul computer;
  • vendor, formato, versione e tracce in cui ogni plugin viene usato.
  • the Ableton Live version used by the set;
  • tracks, groups and Returns;
  • routing, sends and effect chains;
  • required VST2, VST3 and Audio Units;
  • a comparison with the plugins installed on the computer;
  • vendor, format, version and the tracks where every plug-in is used.

Nuovo nella 1.0.1: Media Health

New in 1.0.1: Media Health

Controlla se i sample audio di clip, Simpler e Sampler sono realmente disponibili. La tab Media mostra file trovati e mancanti, percorsi risolti, tracce coinvolte e permette di copiare la lista dei file mancanti o esportare un CSV.

Check whether audio samples used by clips, Simpler and Sampler are truly available. The Media tab shows found and missing files, resolved paths and affected tracks, and can copy the missing list or export a CSV.

Navigazione tra plugin e tracce

Navigate between plug-ins and tracks

Filtra la Plugin map per produttore, apri direttamente la traccia in Session map e torna al requisito del plugin con un clic. I plugin non disponibili localmente sono indicati in modo discreto nella catena della traccia.

Filter the Plugin map by vendor, open the matching track in Session map and return to the plug-in requirement with one click. Plug-ins unavailable locally are marked discreetly in the track chain.

Progetti vecchi, decisioni rapide

Old projects, quick decisions

Prima di cercare vecchi plugin o installare una versione diversa di Live, verifica cosa manca davvero. AblVST Studio aiuta a ridurre tentativi inutili e a individuare le dipendenze di un set.

Before looking for old plugins or installing a different version of Live, check what is actually missing. AblVST Studio helps reduce unnecessary trial and error and identify a set's dependencies.

Locale e privato

Local and private

L'analisi avviene sul tuo computer. Nessun file .als, nome di progetto o elenco di plugin viene caricato su server esterni.

Analysis happens on your computer. No .als file, project name or plugin list is uploaded to external servers.
