AblVST Studio

Vuoi sapere cosa contiene un Live Set prima ancora di aprirlo? AblVST Studio legge i file .als in sola lettura e ne ricava una mappa chiara: tracce, dispositivi, plugin, media, routing e dipendenze, tutto a colpo d'occhio.

Want to know what's inside a Live Set before you open it? AblVST Studio reads .als files in read-only mode and turns them into a clear map of tracks, devices, plug-ins, media, routing and dependencies, all at a glance.

UN PROGETTO ORDINATO È IL PUNTO DI PARTENZA
A WELL-ORGANIZED PROJECT IS THE STARTING POINT

E’ importante avere una struttura ordinata dei propri progetti

A well-organized project structure matters

Prima: una struttura fatta bene

First: keep your project archive organized

Tieni una cartella generale, per esempio Progetti di Ableton, con una sottocartella per ogni progetto. Dentro conserva i file .als insieme a Samples, Backup e agli altri file collegati. Se i percorsi sono sparsi o l'archivio è incompleto, nessun lettore — nemmeno questo — può darti una lettura davvero fedele.

Keep one main folder, such as Ableton Projects, with a subfolder for each project. Store each .als file together with Samples, Backup and the other related files. If paths are scattered or the archive is incomplete, no reader — including this one — can give you a truly faithful picture.

Libreria di Set

Set library

Scansiona la cartella generale e AblVST Studio troverà i Set, mostrando solo la versione più recente o, a scelta, tutte quelle presenti. Ricorda l'ultima cartella e l'ultimo Set che hai analizzato, così riprendi da dove avevi lasciato.

Scan the main folder and AblVST Studio will find your Sets, showing only the newest version or, if you prefer, every version. It remembers the last folder and Set you inspected, so you can pick up where you left off.

Panoramica tecnica del Set

Technical Set overview

Trovi subito versione di Ableton Live, BPM, indicazione di tempo e dimensione del file. Sotto, l'inventario completo del progetto: tracce audio e MIDI, gruppi, Return, Master, clip e dispositivi.

You immediately see the Ableton Live version, BPM, time signature and file size. Below that is the complete project inventory: audio and MIDI tracks, groups, Returns, Master, clips and devices.

Plugin map

Plugin map

Ogni plugin di terze parti viene elencato con nome, produttore, formato, tipo, identificatore, numero di istanze, tracce, Rack e posizione. Puoi filtrare per plugin mancanti o disponibili e saltare direttamente dalla mappa alla traccia che lo usa.

Each third-party plug-in is listed with its name, vendor, format, type, identifier, instance count, tracks, Rack and position. Filter for missing or available plug-ins and jump straight from the map to the track that uses it.

Database locale dei plugin

Local plug-in database

Scansiona i plugin installati sul computer e costruisce un inventario ricercabile, raggruppabile per nome, produttore, formato, tipo, versione, architettura o percorso.

Scan the plug-ins installed on your computer and build a searchable inventory that you can group by name, vendor, format, type, version, architecture or path.

Media Health

Media Health

Controlla i riferimenti audio di clip, Simpler e Sampler/MultiSampler sui percorsi salvati, e ti dice cosa è stato trovato, cosa manca, da dove arriva il percorso e quali tracce o dispositivi lo usano. I file supportati si riproducono al volo con un semplice clic sul nome del media, la loro posizione si apre con un clic, e la lista dei mancanti si copia o si esporta.

Check the audio references used by clips, Simpler and Sampler/MultiSampler against their saved paths. See what was found, what is missing, where each path comes from, and which tracks or devices use it. Supported files play when you click the media name; open their location with a click, and copy or export the missing-file list.

Session map e Rack annidati

Session map and nested Racks

Mostra la gerarchia delle tracce, le device-chain, i Rack annidati e i dispositivi interni. I plugin mancanti vengono segnalati direttamente nella catena della traccia, con un collegamento diretto alla Plugin map.

View the track hierarchy, device chains, nested Racks and internal devices. Missing plug-ins are flagged directly in the track chain, with a link back to the Plugin map.

Routing e flusso del segnale

Routing and signal flow

Analizza mandate, Return, catene effetti e le tracce che alimentano ogni Return, rendendo leggibile il flusso del segnale senza dover aprire Ableton Live.

Analyze sends, Returns, effect chains and the tracks feeding each Return, making the signal flow easy to understand without opening Ableton Live.

Export professionale del Set

Professional Set export

Esporta la lista dei plugin richiesti in CSV o PDF: modalità Summary, una riga per plugin, oppure Detailed, con una riga per ogni istanza, traccia, gruppo, Rack e posizione.

Export the list of required plug-ins as CSV or PDF: Summary mode gives one row per plug-in; Detailed mode gives one row for every instance, track, group, Rack and position.

I report indicano nome del Set, versione di Live, utilizzo e disponibilità locale, e vengono generati offline senza scrivere nulla accanto al file .als.

Reports show the Set name, Live version, usage and local availability. They are generated offline without writing anything next to the .als file.

Preferenze e diagnostica

Preferences and troubleshooting

Da qui gestisci le versioni di Ableton Live installate, le cartelle plugin standard e personalizzate, la visibilità delle versioni dei Set, la lingua, la cache e il log dell'applicazione.

Manage installed Ableton Live versions, standard and custom plug-in folders, visibility of Set versions, language, cache and the application log.

Apri con la versione giusta di Live

Open with the right Live version

Se sul computer ci sono più versioni di Ableton Live installate, AblVST Studio ti mostra quelle compatibili con il Set e puoi decidere con quale versione di Ableton Live aprire il progetto.

If multiple versions of Ableton Live are installed on your computer, AblVST Studio shows which ones are compatible with the Set, and you can choose which version to use to open the project.

Windows e macOS

Windows and macOS

Su Windows vengono rilevati i plugin VST2 e VST3, inclusi i VST3 in formato file e bundle. Su macOS sono supportati anche gli Audio Units, oltre a VST2 e VST3. L'app macOS gira in una finestra nativa Cocoa/WebKit e non dipende da Chrome.

On Windows, VST2 and VST3 plug-ins are detected, including VST3 plug-ins in both file and bundle formats. On macOS, Audio Units are supported alongside VST2 and VST3. The macOS app runs in a native Cocoa/WebKit window and does not depend on Chrome.

Offline e privato

Offline and private

L'analisi dei Set avviene interamente sul tuo computer. I file originali non vengono toccati, i dati derivati restano nella cache locale e nessun progetto o metadato viene mai caricato online.

Set analysis happens entirely on your computer. Original files are never modified, derived data stays in the local cache, and no project or metadata is ever uploaded online.
